# Contributing

Thanks for helping improve LLM Gateway.

1. Create a focused branch from `main`.
2. Keep provider-specific logic inside provider adapters.
3. Do not commit credentials, real prompts or generated secrets.
4. Add or update unit/e2e coverage for behavior changes.
5. Run `npm test`, `npm run lint` and `npm run build` before opening a pull request.
6. Keep public API compatibility unless the change is intentional and documented.

Small, focused pull requests are easier to review and safer to merge.
